# 工事黒板カメラ 2.2.0

iPhoneのSafariで公開URLを開き、ホーム画面に追加してアイコンから起動します。
管理者が発行したメール・パスワードでログインし、表示される12桁の照合番号を管理者に伝えてください。承認後は「利用状態を確認」を押し、写真庫のパスコードで開きます。
初回と30日ごとの自動認証には通信が必要です。認証後は期限まで圏外で撮影できます。機種変更の前に写真を暗号化バックアップしてください。
撮影画面は縦持ちでも使えます。写真は画面中央の横長4:3の枠どおりに保存され、縦持ちでは上下が切れます。
「事前登録」→「＋ 新規登録」でテンプレート名と黒板の項目を入力し、「保存」を押します。撮影時はカメラ画面上部で名前を選びます。

## 写真の記録と中断後の再開

撮影直後の「端末に記録中…」は、画像と黒板の内容を暗号化して書き込んでいる途中です。この間にアプリを終了すると、その写真を復旧できないことがあります。
「記録済み」と表示された写真は端末に保存済みで、JPEGとサムネイルの仕上げが中断しても、次に写真庫を開いたときに仕上げを再開します。一覧の枚数は仕上げ完了後に増えます。
「仕上げ待ち」の場合は空き容量を確認し、写真庫をロックして開き直してください。全写真の暗号化バックアップは、記録済みの写真の仕上げが完了してから行います。

## 旧版からの更新と写真庫の引き継ぎ

同じ公開URL・同じブラウザーの保存領域で更新した場合、旧版の写真庫は以前の写真用パスコードで開きます。利用認証のなかった旧版の写真庫は、最初に利用認証・端末承認を通過した利用者に引き継がれます。別の利用者には別の写真庫が開かれます。

1. 更新前に「設定 → 全写真を暗号化バックアップ」で、仕上げ済みの写真の `.kbk` ファイルを保存します。
2. GitHub Pagesの公開完了後、通信できる場所でアプリを開き、記録中の写真がないことを確認してから閉じて開き直します。
3. メール・パスワード認証と端末承認を済ませ、以前の写真用パスコードで写真庫を開きます。「設定」のバージョン、写真一覧、既存テンプレートを確認します。

旧版が別の画面で開いたままだと、写真庫の更新を妨げることがあります。案内が出た場合はそちらの画面を閉じてから再試行してください。更新のためにSafariのWebサイトデータや写真庫を消去する必要はありません。消去すると端末内の写真も失われます。

## 暗号化バックアップからの復元

1. 移行元で仕上げ済みの写真を `.kbk` に書き出し、ファイルを移行先へコピーします。
2. 移行先で利用認証・端末承認を済ませ、写真庫を開きます。別の端末やブラウザーの保存領域では、新たな端末承認が必要です。
3. 「設定 → 暗号化バックアップから復元」でファイルを選び、書き出したときのバックアップ用パスワードを入力します。
4. 復元結果の追加・省略・除外枚数と、写真一覧の画像を確認します。確認が済むまで移行元とバックアップファイルを残してください。

写真用パスコードとバックアップ用パスワードは別です。同じ写真IDが既にある場合は省略し、既存写真を上書きしません。JPEGが欠けている、または保存されたSHA-256と一致しない写真は除外します。メタデータの形式が不正な場合などは復元を途中で中断します。途中でエラーが出た場合は、完了したものと決めつけず、結果と写真一覧を確認してください。

## 端末承認と30日ごとの確認

承認待ちの端末は写真庫を開けません。承認後に取得した利用許可は最大30日間有効で、起動や通信復帰だけでは期限を延長しません。期限後は通信できるときにセッションを更新し、利用者と端末の許可を再確認します。セッションが失効している場合はパスワードの再入力が必要です。

管理者が利用者または端末を停止しても、取得済みの許可は期限まで有効です。オンラインでも停止の反映まで最長30日かかります。PR #1の旧説明にあった「おおむね1分ごとのサーバーでの停止確認」は、現行2.2.0の動作ではありません。
