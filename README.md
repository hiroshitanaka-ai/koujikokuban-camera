# 工事黒板カメラ 2.2.0

iPhoneのSafariで公開URLを開き、ホーム画面に追加してアイコンから起動します。
管理者が発行したメール・パスワードでログインし、表示される12桁の照合番号を管理者に伝えてください。承認後は「利用状態を確認」を押し、写真庫のパスコードで開きます。
初回と30日ごとの自動認証には通信が必要です。認証後は期限まで圏外で撮影できます。機種変更の前に写真を暗号化バックアップしてください。
撮影画面は縦持ちでも使えます。写真は画面中央の横長4:3の枠どおりに保存され、縦持ちでは上下が切れます。
「事前登録」→「＋ 新規登録」でテンプレート名と黒板の項目を入力し、「保存」を押します。撮影時はカメラ画面上部で名前を選びます。
